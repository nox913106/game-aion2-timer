# 永恆紀元2計時器

AION 2 的 BOSS 重生與活動倒數工具。單一 HTML 檔，沒有後端、沒有相依套件，開啟即用。

**線上版本：** https://nox913106.github.io/game-aion2-timer/

---

## 兩頁式設計

畫面分成「倒數」與「設定」兩個檢視，同一個項目**只會出現在其中一頁**。

勾選啟用、而且重生時刻在一小時內的項目會自動浮上倒數頁；取消勾選、或按下「已擊殺」讓時間變遠之後，就回到設定頁等待。時間再度逼近時又會自己浮上來，形成循環。

倒數頁最上方是主卡片（最接近的那一項），下方依情況出現幾種卡片：

| 標籤 | 出現條件 |
|---|---|
| 同時 | 與主卡片時刻完全相同的項目，合併成一張卡 |
| 再下一個 | 第一個時刻更晚的項目 |
| 一小時內 | 其餘一小時內的項目 |
| 即將提醒 | 有獨立提醒設定的活動，第一則提醒將在一小時內響起 |
| 需要校時 | 逾期超過一個週期，倒數已失去參考價值 |

每張卡都帶勾選框，可以直接送回設定頁；擊殺後計時的項目另有「已擊殺」，可校時的項目有「校時」。

---

## 功能

- **四種重生規則** — 擊殺後固定間隔、每日固定時刻、每整點、每週固定星期
- **秒級校時** — 滾輪選擇器輸入，套用前即時預覽重生時刻
- **三段語音提醒** — 提前 10 分、提前 5 分、重生前 10 秒，各有不同音效
- **緊迫度閃光** — 剩 10 分黃、5 分橘、1 分紅，越急促閃得越快
- **逐項開關** — 活動時間重疊時，只留要提醒的那幾項
- **合併提醒** — 同一秒觸發的項目併成一則，只播一次音效
- **獨立提醒時刻** — 特定活動可設定專屬的提前分鐘數
- **深色／淺色／跟隨系統** 三種外觀
- **桌面通知** 與 **分頁標題閃爍**
- 設定自動儲存，另有匯出／匯入備份

## 校時

實際重生時間常與理論值有偏移，兩種模式的修正方式不同。

### 固定排程（卡伊拉與五隻 12 小時王）

校時會**整體平移該項目的所有時刻**。例如卡伊拉實際都在 05:00:25 出現，校一次之後 01:00 / 05:00 / … 六場全部跟著移動 25 秒，之後就不必再管。偏移量會顯示在該列的說明文字裡。

### 擊殺後計時（幻夢卡西亞）

打完按「已擊殺」重新計時。忘記按可用「往前 5 分」補時，或用校時直接填入距離下次重生的時間。

### 輸入方式

時 / 分 / 秒三欄滾輪，滑動或直接點選皆可。刻意不用文字輸入框，因為手機的虛擬鍵盤會蓋住「套用」按鈕。「時」的選項上限依該項目的週期產生，不會讓你選到無效值。

輸入時下方即時顯示換算後的重生時刻，確認無誤再按套用。

## 提醒設定

三段提醒可個別開關，勾選時會立即試聽該段音效。提示音（水晶杯）與警報音（管弦樂）的音量分開調整。

音效播放中按 <kbd>Esc</kbd> 或點畫面下方的提示條即可停止。

誤按「已擊殺」時，提示條會出現「復原」按鈕。

## 音效設計

三段提醒使用 Web Audio API 即時合成，沒有任何音檔。

| 提醒 | 長度 | 內容 |
|---|---|---|
| 提前 10 分 | 約 5 秒 | 水晶杯三連敲 × 3 組 |
| 提前 5 分 | 約 10 秒 | 水晶杯五連敲 × 5 組 |
| 重生前 10 秒 | 約 10 秒 | 太鼓漸快、弦樂碎弓、銅管和弦、靜默後衝擊 |

水晶杯的清脆感來自非諧和泛音（2.76、5.40、8.93 倍頻），這是玻璃器皿振動模態的特徵，與樂器的整數倍泛音不同。

最後警報的結構：太鼓 51 擊，間隔由 0.78 秒等比收緊至 0.09 秒；2.6 秒起加入弦樂碎弓；4.2 秒起銅管和弦以遞減時值推進；**9.62 秒全部切斷，靜默 0.38 秒**；10.0 秒次低頻下墜配合跨五個八度的銅管和弦。衝擊前的靜默是關鍵，沒有它落點會被前面的聲音淹沒。

## 桌面通知

Chrome 只在 `https://` 或 `http://localhost` 允許請求通知權限。**用 `file://` 直接開啟檔案一律被擋**，這與 Windows 設定無關。線上版是 https，因此正常運作。設定區的「測試通知」按鈕會顯示目前狀態與失敗原因。

不論通知是否可用，時間到時分頁標題都會閃爍，切到遊戲全螢幕時從工作列也看得到。

程式另外掛了一個 −80 dB 的振盪器（聽不見），讓瀏覽器認定分頁正在播放音訊，藉此規避背景分頁計時器被降頻至一分鐘一次的限制。

> **手機的鎖定畫面無解。** iOS 與 Android 都會在頁面進入背景後不久暫停 JavaScript 執行，計時器隨之停止。這是作業系統層級的限制，網頁無法繞過。要在鎖屏下可靠地收到提醒，需要 Web Push 搭配排程伺服器，已超出單檔工具的範圍。

## 在本機執行

若不想使用線上版，可用內附的腳本在 `localhost` 開啟，桌面通知同樣有效。

```
start-timer.bat    # 雙擊執行
serve.ps1          # 由上者呼叫，PowerShell 內建，無需安裝任何東西
index.html
```

三個檔案放在同一資料夾，雙擊 `start-timer.bat`。腳本使用 `TcpListener` 綁定 `127.0.0.1`，不需要系統管理員權限，也不會觸發防火牆詢問；連接埠被占用時會從 8777 自動往上尋找。黑色視窗需保持開啟，關閉即停止伺服器。

> `serve.ps1` 刻意寫成純 ASCII。Windows PowerShell 5.1 在檔案沒有 BOM 時會以系統 ANSI 編碼讀取 `.ps1`，UTF-8 中文會變成亂碼並導致語法錯誤。

## 資料保存

設定存在瀏覽器的本機儲存空間。**不同網址的資料是分開的** — 從本機檔案改用線上版，或更換瀏覽器、更換裝置時，請先在舊環境按「匯出設定」，再到新環境「匯入設定」。

靜態網站沒有後端，因此無法跨裝置同步。

## 瀏覽器需求

Chrome、Edge、Firefox、Safari 的近期版本。使用了 Web Audio API、CSS 容器查詢、`scroll-snap`、`backdrop-filter`、`prefers-color-scheme`。

## 開發

`index.html`（線上版）與 `boss-timer.html`（本機版）內容相同。

`regress.mjs` 是以 jsdom 進行的回歸測試，涵蓋畫面穩定性、兩頁互斥、主卡片勾選、一小時上限、校時準確度、無鍵盤元件、滾輪欄位七項。修改後執行 `node regress.mjs` 確認沒有回歸。
