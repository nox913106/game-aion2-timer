# 永恆紀元2計時器

AION 2 的 BOSS 重生與活動倒數工具。單一 HTML 檔，沒有後端、沒有相依套件，開啟即用。

**線上版本：** https://nox913106.github.io/game-aion2-timer/

---

## 功能

- **兩欄分類** — BOSS／神將 與 活動 各自成組、各自依時間排序
- **四種重生規則** — 擊殺後固定間隔、每整點、每週固定星期、每日固定時刻
- **三段語音提醒** — 提前 10 分、提前 5 分、重生前 10 秒，各有不同音效
- **逐項開關** — 活動時間重疊時，只勾選要提醒的那幾項
- **合併提醒** — 同一秒觸發的項目會併成一則，只播一次音效
- **獨立提醒時刻** — 特定活動可設定專屬的提前分鐘數，不受共用設定影響
- **深色／淺色／跟隨系統** 三種外觀
- **桌面通知** 與 **分頁標題閃爍**
- 設定自動儲存，另有匯出／匯入備份

## 使用說明

### 擊殺後固定間隔的項目

打完 BOSS 按 **已擊殺** 重新計時。忘記按可用 **往前 5 分** 補時，或按 **校時** 直接填入「距離下次重生還有幾時幾分幾秒」。

### 提醒設定

三段提醒可個別開關，勾選時會立即試聽該段音效。提示音（水晶杯）與警報音（管弦樂）的音量分開調整，各有試聽按鈕。

音效播放中按 <kbd>Esc</kbd> 或點畫面下方的提示條即可停止。

### 資料保存

設定存在瀏覽器的本機儲存空間。**不同網址的資料是分開的** — 從本機檔案改用線上版，或更換瀏覽器時，請先在舊環境按「匯出設定」，再到新環境「匯入設定」。

## 音效設計

三段提醒使用 Web Audio API 即時合成，沒有任何音檔。

| 提醒 | 長度 | 內容 |
|---|---|---|
| 提前 10 分 | 約 5 秒 | 水晶杯三連敲 × 3 組 |
| 提前 5 分 | 約 10 秒 | 水晶杯五連敲 × 5 組 |
| 重生前 10 秒 | 約 10 秒 | 太鼓漸快、弦樂碎弓、銅管和弦、靜默後衝擊 |

水晶杯的清脆感來自非諧和泛音（2.76、5.40、8.93 倍頻），這是玻璃器皿振動模態的特徵，與樂器的整數倍泛音不同。

最後警報的結構：太鼓 51 擊，間隔由 0.78 秒等比收緊至 0.09 秒；2.6 秒起加入弦樂碎弓；4.2 秒起銅管和弦以遞減時值推進；7.0 秒起上升音效掃頻；**9.62 秒全部切斷，靜默 0.38 秒**；10.0 秒次低頻下墜配合跨五個八度的銅管和弦。衝擊前的靜默是關鍵，沒有它落點會被前面的聲音淹沒。

## 桌面通知

Chrome 只在 `https://` 或 `http://localhost` 允許請求通知權限。**用 `file://` 直接開啟檔案一律被擋**，這與 Windows 設定無關。

線上版是 https，因此正常運作。設定區的「測試通知」按鈕會顯示目前狀態與失敗原因。

不論通知是否可用，時間到時分頁標題都會閃爍，切到遊戲全螢幕時從工作列也看得到。

程式另外掛了一個 −80 dB 的振盪器（聽不見），讓瀏覽器認定分頁正在播放音訊，藉此規避背景分頁計時器被降頻至一分鐘一次的限制。

## 在本機執行

若不想使用線上版，可用內附的腳本在 `localhost` 開啟，桌面通知同樣有效。

```
start-timer.bat    # 雙擊執行
serve.ps1          # 由上者呼叫，PowerShell 內建，無需安裝任何東西
index.html
```

三個檔案放在同一資料夾，雙擊 `start-timer.bat`。腳本使用 `TcpListener` 綁定 `127.0.0.1`，不需要系統管理員權限，也不會觸發防火牆詢問；連接埠被占用時會從 8777 自動往上尋找。黑色視窗需保持開啟，關閉即停止伺服器。

> `serve.ps1` 刻意寫成純 ASCII。Windows PowerShell 5.1 在檔案沒有 BOM 時會以系統 ANSI 編碼讀取 `.ps1`，UTF-8 中文會變成亂碼並導致語法錯誤。
